# Fase 2b (dados completos) — Plano de Implementação

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `npm run collect` traz todas as quests reais da TibiaWiki para `data/quests.yaml` (schema v2), com arestas de frase literal marcadas `reviewed: false`, sem tocar no que já foi curado; UI mostra recompensa, região e "não revisada"; publicado.

**Architecture:** Extração é pura em `src/wiki/` (testada com fixtures de wikitext real); I/O fica em `src/wiki/client.ts` (API + cache) e `scripts/collect.ts` (mescla no YAML preservando comentários). Spec: `docs/superpowers/specs/2026-09-12-full-data-design.md`.

**Tech Stack:** o mesmo; `yaml` (já dependência) com Document API para preservar comentários.

## Global Constraints

- Zero `any`/`@ts-ignore`/`as unknown as`; `src/domain/` e `src/wiki/*` exceto `client.ts` puros.
- Nenhuma aresta sem `evidence` literal e `source`. O coletor nunca modifica nem remove entradas existentes.
- User-Agent `tibia-quest-graph/0.2 (fansite data curation; gabrielfernandoi@gmail.com)`; ≤ 50 títulos por chamada; pausa de 300 ms entre chamadas.
- `.cache/` no `.gitignore`.
- Branch `feat/full-data`; commits com `Co-Authored-By: Claude Opus 5 (1M context) <noreply@anthropic.com>`.
